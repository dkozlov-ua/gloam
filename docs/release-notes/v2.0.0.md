# Gloam 2.0.0

Gloam is now a small panel by the clock instead of a tray menu and a dashboard. Click the
tray icon and every setting is there: the profile, each display's gamma and brightness, and
the Media profile. Changes apply as you make them. The panel follows the Windows light or
dark setting and accent colour.

**Removed.** Gloam now does one job: gamma and brightness per display, with two profiles.

- **Calibration** with a colorimeter, and with it the bundled ArgyllCMS. The setup deletes
  ArgyllCMS and the old profile templates from your installation. A calibration profile you
  installed with an earlier version stays in Windows until you remove it; see
  [troubleshooting](https://github.com/dkozlov-ua/gloam/blob/main/docs/troubleshooting.md).
- **Night mode**, its per-app exclusions, and the switch that turned Windows Night Light off.
  Gloam no longer touches Night Light.
- **Color balance**: per-display temperature, tint and RGB gains.
- **Game Lab's game library.** Media no longer switches on by itself while a game runs.

**Profiles.** Normal is each display's own settings. Media changes gamma, brightness and
dark-area visibility on top of them, on every display or one. Switch from the panel, the tray
icon's right-click menu, or `Gloam.exe --profile-set media|normal`. Scripts that switch back
with `--profile-set auto` keep working: `auto` now means `normal`. Your Media settings carry
over; a Media profile that targeted the game's window now covers every display.

**What you see.** Gamma and brightness look exactly as before: the LUTs were compared with
1.11.1's across gamma, white level, brightness and HDR/SDR and are identical.

**Also.** Start with Windows starts Gloam in the tray without opening the panel, and starting
Gloam from the Start menu while it runs opens its panel. Exported diagnostics no longer
garble words that contain your Windows user name.

**Updating from 1.11.1:** 1.11.1 looks for a zip release and cannot install this one from
Check for Updates. Download `Gloam-2.0.0-setup.exe` below and run it once; updates after that
work from the panel. Settings written by 2.0.0 are a new version that 1.11.1 will not
overwrite.
