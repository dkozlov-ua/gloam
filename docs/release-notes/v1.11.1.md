# Gloam 1.11.1

- **`--profile-set` no longer hangs when Gloam isn't running.** Before, `Gloam.exe --profile-set normal|media|auto` turned into the tray app itself when no Gloam was running, so the command never exited and a script or launcher waiting on it stalled until its own timeout. Now it starts Gloam with that profile, waits for it to confirm, and exits with the usual codes: `0` applied, `1` couldn't be saved, `3` Gloam didn't answer. It waits up to 20 seconds for a fresh start, and stops waiting soon after if Gloam fails to start. When Gloam is already running, nothing changes.

Nothing in this release changes calibration math or measured output. No hardware re-validation was needed.
