# Gloam 2.1.0

**An SDR profile.** Next to Normal and Media there is now SDR, which turns Windows HDR off
on every display that supports it and keeps each display's own gamma and brightness. Normal
and Media turn HDR back on. Switch from the panel, the tray icon's right-click menu, or
`Gloam.exe --profile-set sdr`. Gloam sets the HDR mode when you switch profiles and when it
starts; HDR you turn on or off yourself (Win+Alt+B, Settings) stays as you left it until the
next switch.

**What you see: dimming is now a straight dim.** "Keep shadow detail when dimming" and the
Media profile's "Dark-area visibility" are gone from the panel, and saved values for them
are ignored. A display below 100% brightness now dims every level alike, so near-black
detail is a little darker than with the shadow-keeping curve, which was on by default.
Displays at 100% brightness look exactly as before. The saved values stay in settings.json.

**A new icon.** A disc, washed out on one side and true black on the other. The tray icon
shows the profile: in colour for Normal, with a play badge for Media, grey for SDR.

**Also.** Exporting diagnostics while the tests ran no longer left a "Location is not
available" message on the desktop.

**Updating from 2.0.0:** use Check for updates in the panel.
