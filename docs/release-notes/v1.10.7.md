# Gloam 1.10.7

The first release from this fork (`dkozlov-ua/gloam`). It covers everything since 1.10.0.

- **Updates now come from this fork.** Installed copies check `github.com/dkozlov-ua/gloam` for updates, not the upstream repository, so an upstream release won't replace this build.
- **Unsigned build.** This release is built locally without code signing, so Windows SmartScreen may warn the first time you run `Setup.exe`. Choose **More info > Run anyway**.
- **Per-game brightness override.** A Game Lab profile can set its own brightness while the game is active, for example 100% in games and 50% on the desktop. It's opt-in, so existing profiles keep the monitor's brightness.
- **Game Lab is part of the Dashboard.** The separate Game Lab window is gone. Its library and profile editor now live in a section of the Dashboard. New games start on the Reference look.
- **Quick controls on monitor cards.** Each display card on the Dashboard has 2.2 / 2.4 gamma buttons and 100% / 75% / 50% brightness buttons. Other saved adjustments are kept.
- **Left-click the tray icon to open the Dashboard.** Right-click still opens the menu.
- **Simpler interface.** Night mode controls, the Pause Game Mode buttons, the "Windows Default" gamma choice, and the tray's Calibrate Display, Trust Check and Match Displays entries are hidden. Installed calibration profiles keep applying.
- **No global hotkeys.** Gloam no longer registers any Win+Shift shortcuts.

Nothing in this release changes calibration math or measured output. No hardware re-validation was needed.
