# Gloam 1.10.8

- **Two profiles instead of per-game settings.** Game Lab now has **Normal**, which is each monitor's own settings, and **Media**, one settings set shared by every game in your library. Media turns on while a library game is active and switches back to Normal afterwards, as per-game profiles did before.
- **Your settings carry over.** On first launch, Media takes the settings of the game profile you used most recently. If no profile was ever used, Media starts from the default look. Every game stays in the library.
- **Pick a profile from the Dashboard or a script.** The Game Lab status strip has a Profile selector: Automatic, Normal or Media. Scripts can do the same with `Gloam.exe --profile-set normal`, `--profile-set media` or `--profile-set auto`. A manual choice is saved, survives restarts, and holds until you choose Automatic or run `--profile-set auto`.
- **Command-line behavior.** If Gloam is already running, the command goes to that instance. Otherwise Gloam starts with that profile. Exit codes: `0` applied, `1` couldn't be saved, `2` invalid arguments, `3` the running instance didn't answer. To read the exit code, wait for the process, for example `Start-Process Gloam.exe -ArgumentList '--profile-set','media' -Wait -PassThru`.
- **Simpler library.** Each game row has a checkbox that decides whether it switches to Media, plus a remove button. The per-game name and HDR-support fields, and the "apply a look to all games" presets, are gone.
- **Settings format.** Settings move to schema 5. After the first change is saved, older versions can read the file but won't overwrite it.
- **Unsigned build.** Windows SmartScreen may warn the first time you run `Setup.exe`. Choose **More info > Run anyway**.

Nothing in this release changes calibration math or measured output. No hardware re-validation was needed.
