# Gloam 1.11.0

- **A new installer.** The release is now a single `Gloam-1.11.0.zip`. Unzip it and run `powershell -ExecutionPolicy Bypass -File install.ps1`. Gloam installs into `%LOCALAPPDATA%\Programs\Gloam` and adds **Gloam** to the Start menu. No administrator prompt.
- **Updates when you ask.** Gloam no longer checks or downloads anything in the background. **Check for Updates** in the tray menu tells you whether a newer release exists and shows its notes. **Install** downloads it, checks it against the SHA-256 GitHub publishes for it, closes Gloam, replaces the files in the same folder and starts Gloam again.
- **Moving from an earlier version.** Earlier versions (`GloamApp-win-Setup.exe`) cannot update to this one. Uninstall the old Gloam in Settings > Apps first, then install this release and turn **Start with Windows** back on from the tray. Uninstalling the old version removes its startup entry and Start menu shortcut, which is why it goes first. Settings and calibration data in `%LOCALAPPDATA%\Gloam` are kept.
- **Uninstalling.** Run `install.ps1 -Uninstall` from the installation folder. Settings and calibration data stay.
- **Unsigned build.** The installer removes the downloaded-file mark from everything it installs, so SmartScreen does not stop Gloam or the bundled ArgyllCMS tools.

Nothing in this release changes calibration math or measured output. No hardware re-validation was needed.
